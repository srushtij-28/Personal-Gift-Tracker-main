# Personal Gift Tracker

A simple Python command-line application to manage gifts for birthdays,
anniversaries, festivals, and other special occasions.

## Features

- Add gift records
- View all gifts
- Search by person, occasion, or gift name
- Filter gifts by status
- Update gift details
- Delete gift records
- Track planned and actual costs
- Calculate remaining budget
- Display gift statistics
- Store data in JSON format

## Technologies Used

- Python
- JSON
- File Handling
- Lists and Dictionaries
